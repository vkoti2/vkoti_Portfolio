Weather Forecast REST API

Technical documentation for software developers, testers, and API consumers looking to integrate live and forecast weather data into applications.

Audience: Developers & Testers
Auth: Free / None Required

1. Overview

The Open-Meteo Weather Forecast API provides weather forecast data for a specified geographic location. Clients can request current weather conditions, hourly forecasts, and daily summaries through a simple HTTP interface.

The API returns weather data in JSON format, enabling applications to display forecast information, support weather dashboards, and integrate weather data into other services.

2. Purpose

This document explains how to send requests to the Weather Forecast API, configure query parameters, interpret successful responses, and troubleshoot common request errors.

3. Scope

This reference covers the following operations:

  • Retrieve weather forecast data for a geographic location.
  • Select current, hourly, and daily weather variables.
  • Configure temperature units and the response time zone.
  • Interpret response metadata and weather values.

5. Endpoint Reference

5.1 Retrieve Weather Forecast

GET /v1/forecast

Retrieves weather forecast data for the specified geographic coordinates.

Full endpoint URL
https://api.open-meteo.com/v1/forecast

5.2 Query Parameters

Parameter Type Required Description
latitude Number Yes Latitude of the requested location, in decimal degrees.
longitude Number Yes Longitude of the requested location, in decimal degrees.
current String No Comma-separated current weather variables to return.
hourly String No Comma-separated hourly weather variables to return.
daily String No Comma-separated daily weather variables to return.
temperature_unit String No Temperature unit, such as celsius or fahrenheit.
timezone String No Time zone used for returned timestamps, such as Asia/Kolkata.

Note: Parameter names and supported values depend on the provider's current API specification. Refer to the official documentation for the latest details.

5.3 Example Request

The following request retrieves current temperature, relative humidity, and apparent temperature for Hyderabad.

GET Request URL 
GET https://api.open-meteo.com/v1/forecast?latitude=17.3850&longitude=78.4867&current=temperature_2m,relative_humidity_2m,apparent_temperature&timezone=auto
Headers: None required Body: None

5.4 Successful Response

HTTP status: 200 OK. Illustrative response shown below.

JSON Response 
{
  "latitude": 17.375,
  "longitude": 78.5,
  "timezone": "Asia/Kolkata",
  "current": {
    "time": "2026-10-21T11:00",
    "interval": 900,
    "temperature_2m": 29.4,
    "relative_humidity_2m": 58,
    "apparent_temperature": 31.2
  },
  "current_units": {
    "temperature_2m": "°C",
    "relative_humidity_2m": "%",
    "apparent_temperature": "°C"
  }
}

5.5 Response Field Definitions

Field Type Description
latitudeNumberLatitude of the weather grid cell used for the response.
longitudeNumberLongitude of the weather grid cell used for the response.
timezoneStringTime zone used to format the returned timestamps.
current.timeStringTimestamp associated with the current weather reading.
current.intervalNumberInterval between current-condition data points in seconds.
current.temperature_2mNumberAir temperature at approximate 2 meters above ground.
current.relative_humidity_2mNumberRelative humidity at approximately 2 meters above ground.
current.apparent_temperatureNumberApparent temperature adjusted for perceived conditions.
current_unitsObjectUnits associated with the current weather fields.

Important: Weather values vary by location and time. The response shown above is a schema example, not a guaranteed result for every request.

6. Additional Request Examples

Example A: Hourly Temperature Forecast

Returns hourly temperature values and their corresponding timestamps for the requested forecast period.

GET URL 
GET https://api.open-meteo.com/v1/forecast?latitude=17.3850&longitude=78.4867&hourly=temperature_2m&timezone=auto

Example B: Daily Forecast

Returns daily minimum and maximum temperatures and the maximum precipitation probability for each forecast day.

GET URL 
GET https://api.open-meteo.com/v1/forecast?latitude=17.3850&longitude=78.4867&daily=temperature_2m_max,temperature_2m_min,precipitation_probability_max&timezone=auto

7. HTTP Status Codes and Troubleshooting

Status / Condition Meaning Recommended Action
200 OK Request processed successfully. Read and validate the JSON response.
400 Bad Request Request parameters are invalid or incomplete. Check required coordinates, variable names, and parameter values.
429 Too Many A rate or usage limit may have been exceeded. Reduce request frequency and review the provider's usage terms.
5xx Error Server-side or upstream service error. Retry cautiously and check the provider's service status.

The table above is a troubleshooting guide, not a guarantee that every error condition returns the listed status code. Confirm behavior against the current provider documentation.

8. Testing with Postman

  1. 1 Open Postman and create a new GET request.
  2. 2 Paste the full URL with latitude and longitude parameters.
  3. 3 Add optional query parameters such as current, hourly, daily, or timezone.
  4. 4 Click Send and inspect the JSON response body.
  5. 5 Validate status code, selected variables, and units before using the data in production.

9. Limitations and Usage Notes

  • Weather forecasts are estimates and may change as forecast models are updated.
  • Coordinates identify a geographic location; the returned weather grid cell may not match the exact place name or neighborhood.
  • Timestamps depend on the configured time zone.
  • Free API access is intended for eligible non-commercial use and is subject to provider usage terms.
  • Provide appropriate Open-Meteo attribution and comply with the applicable data licensing or usage policy.
